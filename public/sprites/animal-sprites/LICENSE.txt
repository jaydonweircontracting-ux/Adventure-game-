What ships here, and why it complies: the pack contains NO 2D sprites —
only FBX models (Unity + Unreal variants) and one 64x64 texture atlas
(wild_animals_map.png). This folder ships ONLY 2D PNGs rendered from the
Unity FBX models with the pack's own atlas (three.js FBXLoader, local
headless-Chromium render, mirrored to face right, trimmed to the content
box so the image bottom is the feet). NO raw FBX/OBJ/GLB files ship in
the repo or the built site. Rendering to sprites is permitted
modify/include use, not redistribution of the source files.

Files (10): bear, boar, deer_1 (stag), deer_2 (doe), fox, hedgehog
(pack spells it "hedhog"), owl, rabbit, squirrel, wolf.
